# C1-Slim 魔塔

将 LavaXOS 中的 20 层《魔塔》部署到原厂桌面第五个位置，桌面标题显示为“魔塔”，快捷键为 `M`。

本适配使用严格黑白、最近邻缩放与“稳定帧”策略：逐字、过场和连续绘制先在内存中合并，画面稳定或程序等待按键时才提交给电子纸。运行期间只使用快速刷新，退出后直接恢复原厂桌面的已有帧。

魔塔状态栏的三种钥匙使用了不同颜色索引，其中第三种使用索引 0；本适配会将该索引作为黑色图案保留，确保三把钥匙在纯黑白屏上都可见。

安装同时关闭原厂桌面主程序的自动联网更新检查，避免反复弹窗；设置页中的手动“检查更新”入口和系统升级文件均保留。

```powershell
.\scripts\deploy.ps1
```

设备文件位于 `/storage/c1mota`，启动桥为 `/usr/data/m`。安装前的桌面程序和第五个图标备份在 `/storage/c1/recovery/mota`。
