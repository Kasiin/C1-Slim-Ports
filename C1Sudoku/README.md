# C1Sudoku

C1 Slim / MP-D261 的独立单色数独。第三格 `S 数独`，原厂自建改为 `Z`；
Terminal、蛙蛙富翁及其余原厂应用保持不变。

## 操作

- 菜单：上下或 Q/W/E 选择难度，左右选择题号，Enter/OK 开始。
- 有未完成游戏时，开始新题需要二次确认；C 继续存档。
- 棋盘：方向键移动；Q W E R T Y U I O 对应 1～9，不用 Shift。
- Delete 或 P 擦除；Z 撤销本次会话中的操作。
- H 提示：优先清除一处错误数字，否则填入当前空格的答案；累计提示次数。
- N 返回选题菜单；Back 保存退出。Home 不作为游戏退出键。
- 黑底是当前格；粗数字为题目给定，玩家数字带下划线。行/列/宫重复会拒绝输入。
- 右下角显示当前格的候选数；填满正确棋盘显示完成提示。

每次填数/擦除/提示/撤销后自动保存，退出时保存位置。重启后可按 C 继续。
存档路径 `/storage/c1sudoku/save.txt`，新题会替换当前存档；升级不覆盖存档。

## 题库与显示

内置 600 道独立生成的题目，各档 200 道，全部验证唯一解和对应答案：

- 简单：40 个已知数字，可用显式唯一候选逐步解出。
- 普通：32 个已知数字，需要隐式唯一候选，可用两种唯一候选完成。
- 困难：26 个已知数字，仅以上两种方法不能完成，需要更深入推理。

这是算法分级，不承诺与任何商业数独题库的评级一致。题库离线内置，无联网需求。

296×152 真正一位黑白输出，无灰阶、抖动、动画、闪烁光标或定时刷新。
只在画面改变时写帧，限制为至少 90ms 间隔。运行期间沿用蛙蛙富翁的
`fast_refresh_only=1` 和 `refresh_max=100`，退出恢复系统原值。
进出应用保存/恢复原厂 framebuffer，不发模拟按键、不重启 launcher。

## 构建和验证

`scripts/build.ps1` 使用工作区的 Zig 0.14.1、Python 3.12 和 Pillow。
`tools/generate_puzzles.py` 生成或重验 600 题（固定种子），生成的头文件已内置。
`c1sudoku --selftest` 在设备上测试保护题目数字、填数、撤销、提示、存档、损坏
存档拒绝、菜单、Home 隔离及所有题目完成逻辑。
`--preview-menu FILE` / `--preview-game FILE` 输出与实机同格式的二值帧，
用 `tools/render_frame.py` 检查排版。

## 安装与恢复

安装工具对原 launcher 和第三图标做 SHA-256 校验，只接受已审阅的
Terminal + 蛙蛙富翁集成。快捷键表从 `TWEASD` 改为 `TWSAZD`。
安装会重启一次原厂 UI 以加载补丁；正常启动/退出数独不会重启 UI。
原文件备份在 `/storage/c1/recovery/sudoku/`。

不要直接重跑旧的 Terminal/蛙蛙富翁桌面安装程序覆盖此补丁；它们的
hash 白名单通常会拒绝新的 launcher。后续变更应基于数独版继续集成。

字形来自设备自带 GNU Unifont 16.0.01，只保留界面所需字符。
原始字体用于构建，不部署到设备；游戏包含纯黑白的字形子集。
